PART 1: INITIAL SETUP (One-time, ~2 minutes)
═════════════════════════════════════════════════════════════════════════════

Step 1: Open Terminal in VS Code
  • Menu: Terminal → New Terminal
  • Or press: Ctrl+` (backtick)

Step 2: Install LESS globally (Required)
  Command: npm install -g less
  Wait for: "added X packages"

Step 3: Verify LESS installed
  Command: lessc --version
  Expected: Output shows version (e.g., "2.7.1")

Step 4: Done!
  → Build tasks are now ready to use


═════════════════════════════════════════════════════════════════════════════
PART 2: COMPILE LESS TO CSS (Run anytime you edit .less)
═════════════════════════════════════════════════════════════════════════════

Method A: Press Keyboard Shortcut
  Windows/Linux: Press Ctrl+Shift+B
  Mac:           Press Cmd+Shift+B
  
  Then: Select "Build LESS to CSS" from the dropdown
  Wait: ~1 second
  Done: mpgen.css is created/updated in the root folder
  
  Output: "1 file successfully compiled"

Method B: Use Command Palette
  1. Press: Ctrl+Shift+P (Windows/Linux) or Cmd+Shift+P (Mac)
  2. Type: "Tasks: Run Build Task"
  3. Press: Enter
  4. Select: "Build LESS to CSS"
  5. Wait: ~1 second
  6. Done: CSS file created

Method C: Use npm
  1. Open Terminal: Ctrl+` (backtick)
  2. Type: npm run build
  3. Wait: ~1 second
  4. Done: CSS file created


═════════════════════════════════════════════════════════════════════════════
PART 3: WATCH MODE - AUTO COMPILE ON SAVE (For Active Development)
═════════════════════════════════════════════════════════════════════════════

Method A: VS Code Watch Task
  1. Press: Ctrl+Shift+B (Windows/Linux) or Cmd+Shift+B (Mac)
  2. Select: "Watch LESS Files" (second option)
  3. Terminal: Opens and shows "Watching directory 'less/' for changes..."
  4. Edit: Make changes to less/mpgen.less
  5. Save: Press Ctrl+S
  6. Result: Terminal shows "✓ compiled" (~100ms)
  7. Browser: Refresh F5 to see changes
  8. Stop: Press Ctrl+C in terminal when done

Method B: npm Watch
  1. Open Terminal: Ctrl+` (backtick)
  2. Type: npm run watch
  3. Terminal: Shows "Watching directory 'less/' for changes..."
  4-7. Same as Method A
  8. Stop: Press Ctrl+C


═════════════════════════════════════════════════════════════════════════════
PART 4: VERIFY EVERYTHING WORKS
═════════════════════════════════════════════════════════════════════════════

After running the build:
  
  ✓ Check: mpgen.css file exists in root folder (same level as index.html)
  ✓ Check: File size is ~45-50 KB
  ✓ Check: Contains CSS code (not empty)
  ✓ Check: No errors in VS Code Problem Panel
  ✓ Check: Browser loads without console errors

View the CSS file:
  1. Click: Explorer icon (Ctrl+B)
  2. Look: Root directory
  3. Click: mpgen.css (in root, not in less/ folder)
  4. View: CSS code displayed in editor

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Problem: "lessc not found" error
  Cause: LESS not installed globally
  Fix: Run: npm install -g less
       Then try again

Problem: No output when pressing Ctrl+Shift+B
  Cause: Might need to select task
  Fix: Should show dropdown with 2 options:
       - Build LESS to CSS
       - Watch LESS Files
       If not visible, check that .vscode/tasks.json exists

Problem: CSS file not updating
  Cause: 1) Changes not saved
         2) Wrong file edited
         3) Build didn't run
  Fix: 1) Save file: Ctrl+S
       2) Make sure editing: less/mpgen.less
       3) Run build: Ctrl+Shift+B → "Build LESS to CSS"
       4) Refresh browser: F5

Problem: Changes to .less not showing in browser
  Cause: Browser cache or CSS not compiled
  Fix: 1) Compile: Ctrl+Shift+B → "Build LESS to CSS"
       2) Hard refresh browser: Ctrl+Shift+R (or Cmd+Shift+R)
       3) Open DevTools: F12
       4) Clear cache and reload
       5) Check Console for any errors

═════════════════════════════════════════════════════════════════════════════
WHAT'S HAPPENING BEHIND THE SCENES
═════════════════════════════════════════════════════════════════════════════

When you press Ctrl+Shift+B → "Build LESS to CSS":

  1. VS Code calls: lessc less/mpgen.less less/mpgen.css
  2. lessc reads: less/mpgen.less
  3. lessc processes: Variables, mixins, nesting, etc.
  4. lessc generates: Plain CSS code
  5. lessc writes: less/mpgen.css
  6. Result: CSS file ready for browser

Your browser (when you refresh):
  1. Requests: less/mpgen.css
  2. Downloads: CSS file (45-50 KB)
  3. Parses: CSS rules
  4. Applies: Styles to HTML elements
  5. Result: Styled webpage
