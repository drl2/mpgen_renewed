SESSION OBJECTIVE:
Fix critical regression reported after xlsx-populate migration where dropdowns
failed to populate and Generate Character button was unresponsive.

ISSUE IDENTIFIED:
The src/excel-exporter.js module was accessing window.XlsxPopulate at parse time,
which could prevent app.js from loading and caused silent failures.

SOLUTION IMPLEMENTED:
Implemented deferred access pattern using getXlsxPopulate() function that only
accesses the global window object when the export function is actually called.

CODE CHANGE:
- File: src/excel-exporter.js
- Lines 8-14: Added getXlsxPopulate() function
- Line 55: Updated exportCharacter() to call getXlsxPopulate()
