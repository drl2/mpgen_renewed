About MPGEN

MPGEN is a multi-dimensional character generator designed to create unique and compelling characters across multiple worlds, time periods, species, and cultures.

Features

  • Generate characters with customizable attributes
  • Save and manage your character library locally
  • Export characters to Excel format
  • Explore character generation algorithms
  • Access the latest blog updates

Technology

Built with vanilla HTML, CSS, and JavaScript for maximum performance and compatibility.
